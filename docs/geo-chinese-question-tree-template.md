# Oceanver 中文问题树与答案母版（第一版）

更新：2026-10-11

## 目标与边界

Oceanver 解决**已在使用**手机、宽带服务的账单变化、故障、设备、账户和取消后的问题；BayMediaStar 主站解决**购买前**的套餐选择、申请、转网和报价。不得把 Oceanver 改造成促销站，也不得为同一意图重复创建 URL。

现阶段仅优化已开放的第一批答案页及其内部链接；**不修改索引开关、白名单、canonical、robots 或 sitemap**。公开内容不得声称已查到用户真实账户，不能承诺具体优惠、退款或转网结果。

## 每个问题节点的统一结构

1. **客户原话**：使用用户实际提问方式，尽量只表达一个独立问题。
2. **直接结论**：首屏 40–100 字，回答最可能的情况，明确不是所有账户都相同。
3. **适合谁 / 不适合谁**：区分已在用的客户、首次办理客户和必须先排除的情况。
4. **原因分支**：按可观察的证据分流，不把推测写成事实。
5. **检查步骤**：说明应查看哪两期账单、哪些同名费用、账户折扣或设备状态。
6. **先不要做什么**：列出可能造成失去优惠、号码、设备抵扣或证据的操作。
7. **下一步**：链接上级问题、同级问题及具体后续动作；需账户权限、地址或实时资格时转人工核实。
8. **维护字段**：问题编号、来源类别、适用运营商、最近核对日期、负责人、风险等级、现有 URL、关联节点、证据状态。

来源类别可包括：已核实客服咨询、公开社区提问、Google 评论、运营商公开政策。**未核实案例不得标记为真实客户证据**。不得将个人账户号码、电话、账单截图或其他敏感信息写入公开内容。

## 首批问题树：宽带账单涨价

**母节点：** `/internet/price-hike`

**客户原话：**「我的宽带上个月还便宜，这个月为什么突然涨了？」

**直接结论示例：** 宽带账单上涨不一定是运营商统一调价。先比较最近两期账单的基础月费、促销折扣、自动付款折扣、设备费与一次性收费，找出哪一项发生变化，再判断下个月是否还会持续增加。

| 分支编号 | 观察到的变化 | 下一步判断 | 不应直接推断 |
| --- | --- | --- | --- |
| 网费-01 | 促销折扣减少或消失 | 查看优惠有效期及本期明细 | 不等于所有客户都能续回原价 |
| 网费-02 | AutoPay / 无纸账单折扣消失 | 检查付款方式与折扣资格 | 不等于重新开启就会追溯补发 |
| 网费-03 | Modem / Gateway / 设备费增加 | 区分租赁、购买、一次性设备收费 | 不等于自购设备一定兼容 |
| 网费-04 | 安装、激活、按比例计费等一次性项目 | 核对账单周期和收费说明 | 不等于长期月费已经上涨 |
| 网费-05 | 基础服务月费持续增加 | 核对运营商通知、套餐及账期 | 不等于立刻取消最省钱 |
| 网费-06 | 取消后仍收到收费 | 进入 `/internet/faq/after-cancel-final-bill` | 不等于收费必然错误 |

**先不要做：** 未核对设备归还、服务中断、原有折扣、合同或账户条件前，不要直接取消或重新开户。

**现有上级 / 横向链接：**
- `/bill-optimization`：跨手机和宽带的账单项目核对
- `/internet/faq/after-cancel-final-bill`：取消后的最后账单
- `/internet/home-network-guide`：区分网络质量与费用问题

**人工核实边界：** 具体账户的优惠资格、可调整价格、设备归还责任、退款与最终账单须由有权限的人员或运营商核实。

## 首批问题树：手机账单涨价

**母节点：** `/cellphone/price-hike`

- 手机费-01：基础月费变化 → 对比同名 recurring charge。
- 手机费-02：AutoPay / Paperless 折扣变化 → 核对资格与生效账期。
- 手机费-03：家庭组减线后总额没有按预期下降 → 检查剩余线路重新计价，连接 `/cellphone/family-plan-guide`。
- 手机费-04：Trade-in / Bill Credit 没有到账 → 连接 `/cellphone/faq/promo-credit-not-received`。
- 手机费-05：设备分期、保险、国际功能变化 → 分离服务费与设备费。
- 手机费-06：准备退出家庭计划 → 连接 `/cellphone/family-plan-exit-account-holder`。

**关键警示：** 不要在确认转号资料、设备余额、剩余抵扣及户主权限前取消号码或变更账户。

## 页面落地验收标准

- 页面首屏可独立回答问题；直接结论不能只写「联系我们」。
- 每个分支都有可观察条件、检查动作及不能直接推断的结论。
- 至少有一个上级链接、一个横向相关链接和一个下一步动作；不得指向 404。
- 不得使用未经核实的当前价格、优惠期限或保证结果。
- 需要人工查看账户的地方明确标注，不收集或公开敏感账户信息。
- 不修改已有 URL 的索引策略；发布前检查 build、canonical、实际响应头和页面可访问性。
- 页面更新时间只在内容实际复核后调整。
- 先在现有页面补内容；只有问题意图足够独立、现有页面容纳不了时，才评估新增 URL，并另行审核索引。
